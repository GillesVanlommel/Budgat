# Later / Deferred For V2

These items are intentionally deferred so phase 1 stays focused on making the core model coherent and usable.

## Later Features

- Scheduled transactions
- Recurring transactions
- Savings goals
- Investment goals / portfolio-oriented views
- Forecasting and future cashflow projections
- Split transactions across multiple categories
- Household invitations flow polish
- Advanced permissions inside households
- Import preview with conflict detection
- Better CSV mapping and smart import rules
- Bank sync/import automation
- Transaction attachments / receipt uploads
- Better analytics and trend comparisons across arbitrary periods
- Rollover budgeting as an explicit option
- Budget templates users can reuse
- Category colors/icons
- Merchant/payee management
- Rules-based transaction suggestions
- Multi-currency support
- Notifications and reminders

## Important Product Notes

- Savings and investing should be modeled as transfers to dedicated accounts in phase 1, not as spending.
- Future planning is important, but scheduled transactions should come after the new core model is stable.
- We should resist adding extra features before the household, account, category, transaction, budget, and reconciliation model is fully coherent.
